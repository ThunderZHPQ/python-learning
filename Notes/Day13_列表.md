# Day13 列表

## 一、数据容器

容器是一种可以容纳多份数据的数据类型，容器中的每一份数据称为一个元素。

一个容器可以存储多个元素，元素可以是不同类型的数据，例如：

- 字符串
- 数字
- 布尔值
- 其他数据

Python中常见的数据容器：

- 列表（list）
- 字符串（str）
- 元组（tuple）
- 集合（set）
- 字典（dict）


## 二、列表

列表是一种可以存储多个元素的数据容器。

列表的特点：

- 元素有序
- 元素可以重复
- 元素可以修改
- 可以存储不同类型的数据

例如：

    s = [1, 2, 3, 4, 5, 6, "hello", True]


## 三、列表索引

列表中的每一个元素都有对应的索引，可以通过索引访问元素。

正向索引：

    0    1    2    3    4
    ↓    ↓    ↓    ↓    ↓
    A    B    C    D    E

索引从 `0` 开始。

反向索引：

    -5   -4   -3   -2   -1
     ↓    ↓    ↓    ↓    ↓
     A    B    C    D    E

反向索引从 `-1` 开始。

例如：

    s = [1, 2, 3, 4, 5]

    print(s[0])     # 1
    print(s[-1])    # 5

如果索引超出列表范围，会产生 `IndexError`。


## 四、修改列表元素

列表中的元素可以直接通过索引修改。

    s = [1, 2, 3, 4, 5]

    s[2] = 7

修改后：

    [1, 2, 7, 4, 5]


## 五、删除列表元素

可以使用 `del` 根据索引删除元素。

    s = [1, 2, 3, 4, 5]

    del s[2]

删除后：

    [1, 2, 4, 5]


## 六、遍历列表

可以使用 `for` 循环依次访问列表中的每一个元素。

    s = [1, 2, 3, 4, 5]

    for i in s:
        print(i, end=" ")

输出：

    1 2 3 4 5


## 七、列表切片

切片是从序列中截取其中一部分数据的操作。

列表、字符串、元组都支持切片。

基本语法：

    序列[开始索引:结束索引:步长]

注意：

- 开始索引包含
- 结束索引不包含
- 开始索引省略时默认为0
- 结束索引省略时默认到序列末尾
- 步长省略时默认为1
- 正向索引和反向索引都可以使用

例如：

    s = ["A", "B", "C", "D", "E", "F", "G"]

    print(s[0:6:1])

结果：

    ["A", "B", "C", "D", "E", "F"]

可以省略默认值：

    print(s[:6])

也可以使用反向索引：

    print(s[:-1])

这里 `-1` 对应最后一个元素，但由于切片的结束索引不包含最后一个元素，所以最终得到除最后一个元素之外的内容。


## 八、列表常用方法

### 1. append()

在列表末尾添加一个元素。

    s = [1, 2, 3]
    s.append(100)

结果：

    [1, 2, 3, 100]


### 2. insert()

在指定索引之前插入元素。

    s = [1, 2, 3]
    s.insert(1, 100)

结果：

    [1, 100, 2, 3]


### 3. remove()

删除列表中第一个匹配到的指定元素。

    s = [1, 2, 3, 2]
    s.remove(2)

结果：

    [1, 3, 2]

如果列表中不存在指定元素，会产生错误。


### 4. pop()

删除指定索引位置的元素。

    s = [10, 20, 30, 40]

    s.pop(2)

结果：

    [10, 20, 40]

如果不指定索引：

    s.pop()

默认删除最后一个元素。

`pop()`与`del`的区别之一是：

    pop()

删除元素的同时可以返回被删除的元素。


### 5. sort()

对列表进行排序。

    s = [15, 687, 567, 35, 10, 368, 6]

    s.sort()

结果：

    [6, 10, 15, 35, 368, 567, 687]

列表中的元素需要具有可比较的关系才能正常排序。


### 6. reverse()

将列表中的元素顺序反转。

    s = [1, 2, 3, 4, 5]

    s.reverse()

结果：

    [5, 4, 3, 2, 1]


## 九、今日重点

列表的基本特点：

    有序
    可重复
    可修改
    可以存储不同类型的数据

列表索引：

    正向索引 → 从0开始
    反向索引 → 从-1开始

列表切片：

    s[开始:结束:步长]

注意：

    结束索引不包含


常用列表方法：

    append()   → 末尾添加元素
    insert()   → 指定位置插入元素
    remove()   → 删除指定值
    pop()      → 删除指定位置元素
    sort()     → 排序
    reverse()  → 反转
