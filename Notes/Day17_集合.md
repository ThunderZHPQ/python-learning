# Day17 集合

## 一、集合（set）

集合是一种数据容器，主要具有以下特点：

- 无序
- 元素不可重复
- 可以修改
- 可以存储不同类型的数据

集合会自动去除重复元素。

例如：

```python
s1 = {"A", "B", "C", "D", "A"}

print(s1)
print(type(s1))
```

虽然 `"A"` 出现了两次，但集合中只会保留一个 `"A"`。


## 二、定义集合

使用 `{}` 可以定义集合：

```python
s1 = {"A", "B", "C", "D"}
```

但是不能使用空的 `{}` 定义空集合，因为：

```python
s = {}
```

实际上得到的是一个空字典。

定义空集合需要使用：

```python
s = set()
```

例如：

```python
s2 = set()

print(s2)
print(type(s2))
```


## 三、集合的常用方法

### 1. add()

向集合中添加一个元素。

```python
s1 = {1, 2, 3}

s1.add(4)

print(s1)
```

集合中的元素不能重复，因此如果添加已经存在的元素，不会产生重复数据。


### 2. remove()

移除指定元素。

```python
s1 = {1, 2, 3}

s1.remove(2)

print(s1)
```

注意：

如果指定的元素不存在，`remove()` 会产生错误。


### 3. pop()

随机删除集合中的一个元素，并返回被删除的元素。

```python
s1 = {1, 2, 3}

value = s1.pop()

print(value)
print(s1)
```

由于集合是无序的，因此不能依赖 `pop()` 删除某一个指定元素。


### 4. clear()

清空整个集合。

```python
s1 = {1, 2, 3}

s1.clear()

print(s1)
```


## 四、集合运算

集合非常适合处理类似“共同成员”“独有成员”“所有成员”等问题。

主要有：

- 交集
- 并集
- 差集


## 五、交集 intersection()

交集表示：

> 两个集合中同时存在的元素。

例如：

```python
s1 = {1, 2, 3, 4, 5}
s2 = {1, 2, 3, 6, 7}

print(s1.intersection(s2))
```

结果：

```text
{1, 2, 3}
```

也可以使用 `&` 运算符：

```python
print(s1 & s2)
```

两种写法效果相同。


## 六、并集 union()

并集表示：

> 两个集合中所有不重复的元素。

例如：

```python
s1 = {1, 2, 3, 4}
s2 = {3, 4, 5, 6}

print(s1.union(s2))
```

也可以使用 `|` 运算符：

```python
print(s1 | s2)
```

结果会自动去除重复元素。


## 七、差集 difference()

差集表示：

> 第一个集合中存在，但第二个集合中不存在的元素。

例如：

```python
s1 = {1, 2, 3, 4, 5}
s2 = {3, 4, 5, 6, 7}

print(s1.difference(s2))
```

结果：

```text
{1, 2}
```

也可以使用 `-` 运算符：

```python
print(s1 - s2)
```

注意：

差集具有方向性：

```python
s1 - s2
```

和

```python
s2 - s1
```

结果通常不同。


## 八、集合运算符总结

```text
&   → 交集
|   → 并集
-   → 差集
```

例如：

```python
s1 = {1, 2, 3}
s2 = {2, 3, 4}

print(s1 & s2)  # 交集：{2, 3}
print(s1 | s2)  # 并集：{1, 2, 3, 4}
print(s1 - s2)  # 差集：{1}
```


## 九、集合推导式

集合推导式可以按照一定规则快速创建集合。

基本语法：

```python
{要加入集合的数据 for 变量 in 集合 if 条件}
```

例如：

```python
football_set = {"王林", "曾牛", "徐立国", "遁天"}

fb_set3 = {
    s for s in football_set
    if s not in basketball_set
}
```

这个例子表示：

> 从足球选课学生中筛选出没有选修篮球的学生。

集合推导式和之前学习的列表推导式非常类似，只是：

列表推导式：

```python
[表达式 for 变量 in 序列 if 条件]
```

集合推导式：

```python
{表达式 for 变量 in 集合 if 条件}
```


## 十、学生选课案例

今天使用集合模拟学生选课情况。

```python
football_set = {
    "王林", "曾牛", "徐立国", "遁天",
    "天运子", "韩立", "厉飞雨", "乌丑", "紫灵"
}

basketball_set = {
    "张铁", "墨居仁", "王林", "姜老道",
    "曾牛", "王蝉", "韩立", "天运子",
    "李化元", "厉飞雨", "云露"
}

french_set = {
    "许木", "王卓", "十三", "虎咆",
    "姜老道", "天运子", "红蝶",
    "厉飞雨", "韩立", "曾牛"
}

art_set = {
    "遁天", "天运子", "韩立",
    "虎咆", "姜老道", "紫灵"
}
```


### 1. 同时选修法语和艺术

使用交集：

```python
print(french_set & art_set)
```

也可以使用：

```python
print(french_set.intersection(art_set))
```

得到的就是同时存在于两个集合中的学生。


### 2. 同时选修四门课程

可以连续使用交集：

```python
print(
    french_set
    & art_set
    & basketball_set
    & football_set
)
```

只有同时出现在四个集合中的学生才会被保留下来。


### 3. 选修足球但没有选修篮球

使用差集：

```python
print(football_set - basketball_set)
```

表示：

> 在足球集合中，但是不在篮球集合中的学生。


也可以使用集合推导式：

```python
fb_set3 = {
    s for s in football_set
    if s not in basketball_set
}

print(fb_set3)
```


## 十一、统计每个学生选修的课程数量

首先通过并集得到所有学生：

```python
students = (
    football_set
    | basketball_set
    | french_set
    | art_set
)
```

这样可以得到四门课程中所有出现过的学生，并且自动去重。


然后通过解包，将四个集合中的所有元素放入一个列表：

```python
all_list = [
    *football_set,
    *basketball_set,
    *french_set,
    *art_set
]
```

此时：

- `students`：保存所有不重复的学生
- `all_list`：保存四个课程集合中的所有学生，因此同一个学生可能出现多次


最后遍历所有学生，并使用 `count()` 统计其出现次数：

```python
for s in students:
    print(f"{s}选修了{all_list.count(s)}门课程")
```

例如某个学生同时出现在足球、篮球和法语三个集合中，那么：

```python
all_list.count(s)
```

就会得到 `3`。


## 十二、集合与列表的区别

| 特点 | 列表 list | 集合 set |
| --- | --- | --- |
| 是否有序 | 是 | 否 |
| 是否允许重复 | 允许 | 不允许 |
| 是否可以修改 | 可以 | 可以 |
| 是否支持索引 | 支持 | 不支持 |
| 是否适合查找重复数据 | 一般 | 非常适合 |
| 是否支持集合运算 | 不支持 | 支持 |

简单理解：

- **列表**：重点是保存一组有顺序的数据
- **集合**：重点是去重以及进行集合关系运算


## 十三、今日重点

- 集合使用 `{}` 定义，空集合使用 `set()`
- 集合中的元素不能重复
- 集合是无序的，因此不能通过索引访问元素
- `add()`：添加元素
- `remove()`：删除指定元素，不存在会报错
- `pop()`：随机删除并返回一个元素
- `clear()`：清空集合
- `intersection()` / `&`：求交集
- `union()` / `|`：求并集
- `difference()` / `-`：求差集
- 集合推导式可以快速创建集合
- 集合非常适合处理去重、共同成员、独有成员等问题
