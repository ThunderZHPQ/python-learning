# 1. Python中的四类运算符

Python主要有四类运算符：

1. 算术运算符
2. 比较运算符
3. 逻辑运算符
4. 赋值运算符

# 2. 算术运算符

用于进行数学计算。


| 运算符 | 名称 | 示例 |
|----|----|----|
| + | 加法 | a+b |
| - | 减法 | a-b |
| * | 乘法 | a*b |
| / | 除法 | a/b |
| % | 取余 | a%b |
| // | 整除 | a//b |
| ** | 指数 | a**b |


示例：

```python
a,b = 4,3

print(a+b)
print(a-b)
print(a*b)
print(a/b)
print(a%b)
print(a//b)
print(a**b)
```


运行结果：

```text
7
1
12
1.333...
1
1
64
```

# 3. 运算符优先级


当一个表达式中存在多个运算符时：

Python会按照优先级计算。


优先级从高到低：

```
1. 指数 **
2. 乘法 *、除法 /、取余 %、整除 //
3. 加法 +、减法 -
4. 比较运算符
5. 逻辑运算符
6. 赋值运算符
```


例如：

```python
a + b * 2
```


执行顺序：

```
b * 2
↓
a + 结果
```


如果想改变顺序：

使用括号：

```python
(a+b)*2
```

# 5. BMI计算案例


BMI计算公式：

```
BMI = 体重 / 身高²
```


Python：

```python
bmi = weight / (height ** 2)
```


注意：

float类型可能存在精度问题。


例如：

可能出现：

```
23.333333333333332
```


可以使用格式化控制小数位：


```python
print(f"{bmi:.2f}")
```


表示：

保留两位小数。


例如：

```
23.45
```

# 6. 赋值运算符


用于给变量赋值。


## 基础赋值

```python
a = 5
```


---

## 复合赋值


|写法|等价于|
|-|-|
|a += b|a=a+b|
|a -= b|a=a-b|
|a *= b|a=a*b|
|a /= b|a=a/b|
|a %= b|a=a%b|
|a //= b|a=a//b|
|a **= b|a=a**b|


示例：

```python
a = 5

a += 10
```


等价：

```python
a = a + 10
```


结果：

```
15
```


注意：

赋值语句不能直接放入print参数：

错误：

```python
print(a += 10)
```


原因：

`+=`是赋值操作，不是表达式。

# 7. 比较运算符


用于比较两个值。


|符号|含义|
|-|-|
|==|等于|
|!=|不等于|
|>|大于|
|<|小于|
|>=|大于等于|
|<=|小于等于|


示例：

```python
a,b = 5,10

print(a>b)
print(a<b)
```


结果：

```text
False
True
```


比较运算返回：

```python
True
False
```


即：

布尔类型。


---

# 8. 逻辑运算符


用于多个条件组合。


三个逻辑运算：

|运算符|含义|
|-|-|
|and|并且|
|or|或者|
|not|取反|


---

## and

两个条件同时成立：

```python
True and True
```


结果：

```
True
```


例如：

判断数字是否在10-20之间：

```python
num > 10 and num < 20
```


---

## or

任意一个条件成立：

```python
True or False
```


结果：

```
True
```


例如：

判断数字不在10-20：

```python
num < 10 or num > 20
```


---

## not

取反：

```python
not True
```


结果：

```
False
```
